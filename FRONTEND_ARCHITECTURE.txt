=================================
URL & PAGE STRUCTURE
=================================

Homepage "/"
├── Path: /
├── Component: App.tsx
├── State: chats = []
├── Condition: chats.length === 0
└── Rendered: WelcomeScreen
    ├── Heading: "Welcome to Build Your Own Agent"
    ├── InputForm (hasHistory=false)
    │   ├── Agent Selector
    │   ├── Model Selector
    │   ├── Mode Selector
    │   ├── Text Input
    │   └── Send Button
    └── Footer text

Conversation Page "/c/:conversationId"
├── Path: /c/{number}
├── Component: App.tsx
├── State: chats = [messages from API]
├── Condition: chats.length > 0
└── Rendered: ChatMessagesView
    ├── ScrollArea
    │   └── map chats.map(msg => Bubble)
    │       ├── UserMessageBubble (right aligned)
    │       └── AiMessageBubble (left aligned)
    │           ├── ActivityTimeline (if has activities)
    │           ├── ThinkingStream (if thinking)
    │           └── Message content (markdown)
    │
    └── InputForm (hasHistory=true)
        ├── Agent Selector
        ├── Model Selector
        ├── Mode Selector
        ├── Text Input
        ├── Send Button
        └── [New Search] button -> window.location.reload()

=================================
STATE MANAGEMENT
=================================

App.tsx manages:
├── chats: ChatMessage[] - all messages
├── conversationId: string | undefined - from URL
├── selectedAgent: AgentType - current agent
├── isLoading: boolean - request in progress
├── processedEventsTimeline: ProcessedEvent[] - live activities
├── historicalActivities: { [messageId]: ProcessedEvent[] } - past activities
├── thinkingContent: string - AI thinking
└── isThinking: boolean - is currently thinking

Data flows:
├── conversationId -> from useParams()
├── selectedAgent -> from localStorage (via useSelectedAgent hook)
└── chats -> from API response or user input

=================================
ROUTING DEFINITION
=================================

Frontend uses React Router v7 (main.tsx):

<BrowserRouter>
  <Routes>
    <Route path="/" element={<App />} />
    <Route path="/c/:conversationId" element={<App />} />
  </Routes>
</BrowserRouter>

Same App component handles both routes.
App.tsx uses:
  - useParams<{conversationId: string}>()
  - useNavigate()
  - useEffect to fetch conversation if conversationId exists
  - conditional render based on chats.length

=================================
API ENDPOINTS
=================================

POST /backend/agent/{agentURL}
├── Body: { id: number, messages: ChatMessage[] }
└── Returns: streaming Response with JSON events
    ├── {stage: 'metadata', conversation_id: number}
    ├── {stage: 'thinking', response: string}
    ├── {stage: 'tool_result', tool: string, result: string}
    ├── {stage: 'content', response: string}
    └── {stage: 'finalize_answer'}

GET /backend/{agentURL}/conversation/{conversationId}
├── Query: conversationId (number)
└── Returns: Conversation {
    id, created_at, updated_at, title, model, 
    metadata, messages: ChatMessage[]
  }
